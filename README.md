# depviz

Инструмент визуализации графа зависимостей пакетов Python (pip).
Практическая работа №2 «Конфигурационное управление», вариант 1.

## Параметры командной строки

| Опция | Описание |
|-------|----------|
| `-p`, `--package` | имя анализируемого пакета (обязательно) |
| `-r`, `--repo` | URL репозитория или путь к файлу тестового репозитория |
| `-t`, `--test-mode` | режим работы с тестовым репозиторием |
| `-o`, `--output` | имя файла с изображением графа (`.svg`) |
| `-a`, `--ascii-tree` | вывести зависимости в виде ASCII-дерева |
| `-d`, `--max-depth` | максимальная глубина анализа (0..100) |

## Запуск и тесты

```
./run.sh --package requests
./run_tests.sh
```

## Этап 2. Сбор данных

Прямые зависимости пакета читаются из JSON-описания, которое отдаёт
репозиторий по адресу `<repo>/<package>/json` (формат PyPI).
Используется только стандартная библиотека Python (`urllib`, `json`).

```
./run.sh --package requests
```

## Этап 3. Основные операции

Граф строится обходом в глубину (DFS) без рекурсии, с учётом
максимальной глубины `--max-depth`. Циклические зависимости не приводят
к зацикливанию и выводятся отдельным списком. Тестовый репозиторий
(`--test-mode`) — текстовый файл, где пакеты названы заглавными латинскими
буквами: `A: B C` означает «A зависит от B и C».

```
./run.sh -t -r examples/cycle.txt -p A -d 10
```

## Этап 4. Дополнительные операции

Опция `--reverse` выводит обратные зависимости — пакеты, которые зависят
от заданного. Используется тот же обход, что и на этапе 3, но по графу с
перевёрнутыми рёбрами. В тестовом репозитории ищутся все пакеты файла. У
реального репозитория pip нет индекса зависимых пакетов, поэтому они
ищутся среди пакетов из `--candidates`.

```
./run.sh -t -R -r examples/diamond.txt -p D -d 5
./run.sh -R -p idna -c requests,flask
```
